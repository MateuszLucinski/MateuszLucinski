### 🚀 Featured Projects

#### 🧬 [Darwinian Evolution Simulator](https://github.com/Skczu/PO_2025_SR1315_OLUBIEC_LUCINSKI)
![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white) ![JavaFX](https://img.shields.io/badge/javafx-%23FF0000.svg?style=for-the-badge&logo=java&logoColor=white)
> *A dynamic, graphical simulator of Darwinian evolution where a population of creatures adapts to its environment, mutations, and energy constraints.*
* **What I did:** Built a responsive GUI using **JavaFX** with real-time animation, multi-simulation support, live statistical charts, and CSV data export.
* **Key concepts:** Advanced Object-Oriented Programming, algorithm design for genetic crossing and mutation, performance optimization for rendering large grid states.

#### 🎟️ [High-Concurrency Ticket Reservation System](https://github.com/Rurek404/DB)
![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=for-the-badge&logo=postgresql&logoColor=white) ![Hibernate](https://img.shields.io/badge/Hibernate-59666C?style=for-the-badge&logo=Hibernate&logoColor=white)
> *A robust backend system for event ticket sales, specifically architected to prevent race conditions and overbooking during high-traffic traffic spikes.*
* **What I did:** Implemented a multi-layered concurrency defense system. I combined application-level transaction management with **PostgreSQL pessimistic row-locking** (`SELECT ... FOR UPDATE`) and strict **PL/pgSQL triggers**.
* **Key concepts:** ACID transactions, mitigating Phantom Reads, database-level integrity, Hibernate advanced mappings (`@Formula`), native SQL reporting, and multithreaded testing.

#### 🛒 [E-Shop Microservices Platform](https://github.com/MateuszLucinski/e_shop_project)
![NodeJS](https://img.shields.io/badge/node.js-6DA55F?style=for-the-badge&logo=node.js&logoColor=white) ![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB) ![TypeScript](https://img.shields.io/badge/typescript-%23007ACC.svg?style=for-the-badge&logo=typescript&logoColor=white)
> *A full-stack e-commerce application designed with a modern microservices architecture.*
* **What I did:** Developed three independent backend services (Products, Orders, Users) running on separate Node.js/Express instances with SQLite databases. Secured the API with **JWT authentication** and Role-Based Access Control.
